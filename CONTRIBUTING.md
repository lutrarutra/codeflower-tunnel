# Contributing

Thank you for helping. Before a pull request can be merged, you sign the contributor license
agreement (CLA). CLA Assistant asks you on your first pull request. The CLA lets the project offer
the tunnel under terms other than the AGPL as well, which pays for the hosted service.

Run `npm test` and `npm run check` before opening a pull request. A change to the protocol
changes [PROTOCOL.md](PROTOCOL.md), and needs matching changes in codeflower-app (the connector)
and codeflower-ui (the browser side).
